# Besi Rasyon

Besi sığırı için en ucuz dengeli yem karışımını hesaplayan uygulama (NRC besi sığırı standartları).

**Uygulama:** https://nuhbektas-max.github.io/besi-rasyon/

## iPhone ve iPad'e kurulum

1. Yukarıdaki adresi **Safari**'de açın.
2. Alttaki **Paylaş** düğmesine (yukarı oklu kare) dokunun.
3. **Ana Ekrana Ekle**'yi seçin.

Uygulama ana ekranda simgesiyle açılır ve internetsiz çalışır. Bilgileriniz yalnızca telefonda saklanır.

Bu depoda yalnızca uygulamanın yayınlanan dosyaları bulunur.
